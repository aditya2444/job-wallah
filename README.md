# 🚀 Job Wallah (Jobs & Internships Portal)

A modern, fast, and feature-packed web application inspired by **Internshala**, customized with the **"Job Wallah"** branding. Designed and architected by **Prince Chaurasiya** for Indian students, fresh graduates, and recruiters.

---

## ✨ Key Features & Highlights

### 1. 🎨 Internshala-Inspired Design System & Visual Polish
- Signature clean typography, responsive layout, and distinct color accents (`#008BDC` Internshala blue, `#FFB703` accent amber, and crisp white cards).
- Custom vector branding logo for **Job Wallah** with career rocket & grad cap motifs.
- Hero section with dual-column layout, real-time search box, curated search pills, and floating trust badges (*500K+ Students Placed*, *₹18 LPA Peak CTC*).
- Trust metrics bar (300K+ Companies Hiring, 10,000+ New Openings, ₹18 LPA Highest Package, 100% Verified).

### 2. ⚡ Skeleton Screen While Loading
- Shimmer skeleton loaders matching the exact shape of Job Wallah / Internshala cards (company logo, title, location, 4-grid metadata, tags, and action buttons).
- Renders upon page boot and during filter/search switches for a native-app feel.

### 3. 📱 Multi-Device Navigation (Mobile, Tablet, Desktop)
- **Desktop Navigation**: Clean sticky navbar with dropdown items, Bookmarks counter badge, Applications tracker badge, and "Hire Talent" CTA.
- **Mobile Hamburger Drawer**: Slide-out navigation drawer with quick access to all platform pages, user activity, legal policies, and creator credit.
- **Mobile Bottom Navigation Bar**: Fixed 5-tab bar on mobile devices (Home, Internships, About/Careers, Saved, My Applications) matching Internshala's mobile app experience.
- **Mobile Filter Trigger**: Instant one-tap button to open filter and search controls on smaller screens.

### 4. 🏷️ "Designed & Made by Prince Chaurasiya"
- Distinctive interactive credit badge on the footer of all 22 pages and inside the mobile navigation drawer.
- Clicking the badge opens an interactive **Creator Profile Modal** celebrating Prince Chaurasiya's architecture and design of Job Wallah.

## 🏃 How to Run the Website

### Option 1: Run with Node.js (Recommended)
```bash
npm start
```
*or*
```bash
node server.js
```
Then open [http://localhost:3000](http://localhost:3000) in your web browser.

### Option 2: Run with Python 3
```bash
python3 -m http.server 3000
```
Then open [http://localhost:3000](http://localhost:3000).

### Option 3: Direct File Opening
Double-click [index.html](file:///home/keshava__dasa/Projects/Job%20Wallah/index.html) to open it directly in any browser.
